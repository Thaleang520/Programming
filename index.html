Example

គឺជាផ្នែកតួខ្លួននៃឯកសារ HTML ដែលផ្ទុកនូវរាល់មាតិកាទាំងអស់ដែលត្រូវបង្ហាញឱ្យអ្នកប្រើប្រាស់មើលឃើញផ្ទាល់នៅលើកញ្ចក់អេក្រង់។ រាល់អត្ថបទ រូបភាព វីដេអូ ប៊ូតុង និងតំណភ្ជាប់ទាំងឡាយ ត្រូវតែសរសេរនៅក្នុងចន្លោះ tag បើក <body> និង tag បិទ </body> នេះ។
Syntax <body><!-- Visible content --></body>
5 <title></title>
គឺជាធាតុដែលប្រើសម្រាប់កំណត់ចំណងជើងនៃទំព័រគេហទំព័រ។ វាជាកូដដែលត្រូវតែសរសេរនៅក្នុងផ្នែក <head></head> ជានិច្ច ហើយអត្ថបទនៅក្នុង tag នេះនឹងមិនបង្ហាញនៅលើផ្ទៃទំព័រវិបផ្ទាល់នោះទេ។
Syntax <title>Page Title</title>
6 <meta>
ប្រើសម្រាប់កំណត់ព័ត៌មានលម្អិត (Metadata) អំពីទំព័រវិប។ វាជា Empty Tag (មានតែ tag បើក គ្មាន tag បិទ </meta> ទេ) ហើយត្រូវសរសេរនៅក្នុងផ្នែក <head></head> ជានិច្ច។ ព័ត៌មានទាំងនេះមិនបង្ហាញលើទំព័រវិបទេ ប៉ុន្តែវាជួយប្រាប់ Browser និងម៉ាស៊ីនស្វែងរក (Google) ឱ្យយល់ពីទំព័រវិបរបស់អ្នក។
6.1 Character Encoding
គឺជាកូដបញ្ជាក់ទម្រង់អក្សរ (Character Encoding) នៅក្នុងឯកសារ HTML។ វាប្រាប់ទៅកាន់កម្មវិធីរុករកបណ្ដាញ (Web Browser) ឱ្យបង្ហាញអក្សរ និមិត្តសញ្ញា និងសញ្ញាអារម្មណ៍ (Emojis) គ្រប់ភាសាទាំងអស់លើពិភពលោកបានត្រឹមត្រូវ និងមិនឱ្យចេញអក្សរការ៉េៗ ឬអក្សររញ៉េរញ៉ៃឡើយ
Syntax <meta charset="UTF-8">
6.2 Viewport
គឺជាកូដសម្រាប់កំណត់ទំហំបង្ហាញ (Responsive Web Design) នៅក្នុងឯកសារ HTML។ វាប្រាប់ទៅកាន់កម្មវិធីរុករកបណ្ដាញ (Web Browser) លើទូរស័ព្ទដៃ ឬ Tablet ឱ្យតម្រូវទំហំគេហទំព័រទៅតាមទំហំអេក្រង់ឧបករណ៍នីមួយៗដោយស្វ័យប្រវត្ត ដើម្បីកុំឱ្យអ្នកប្រើប្រាស់ពិបាកពង្រីក (Zoom) មើល។
Syntax <meta name="viewport" content="width=device-width, initial-scale=1.0">
6.3 Description
គឺជាកូដសម្រាប់ពិពណ៌នាខ្លឹមសារសង្ខេបរបស់គេហទំព័រទៅកាន់ម៉ាស៊ីនស្វែងរក (Search Engines) ដូចជា Google ជាដើម។ វាជួយឱ្យ Google ដឹងថាទំព័រ Web របស់អ្នកនិយាយពីអ្វី ហើយវានឹងបង្ហាញអត្ថបទខ្លីនេះនៅលើលទ្ធផលនៃការស្វែងរក (Search Result Snippet) នៅក្រោមចំណងជើងគេហទំព័ររបស់អ្នក។
Syntax <meta name="description" content="This is my website.">
6.4 Keywords
គឺជាកូដសម្រាប់បញ្ជាក់ពីពាក្យគន្លឹះ (Keywords) នៃខ្លឹមសារគេហទំព័ររបស់អ្នក។ កាលពីមុន វាត្រូវបានគេប្រើប្រាស់ដើម្បីប្រាប់ទៅកាន់ម៉ាស៊ីនស្វែងរក (Search Engines) ដូចជា Google, Yahoo, ឬ Bing ឱ្យដឹងថាទំព័រ Web របស់អ្នកមានទំនាក់ទំនងនឹងប្រធានបទអ្វីខ្លះ (ក្នុងឧទាហរណ៍នេះគឺ HTML, CSS, និង JavaScript)។
Syntax <meta name="keywords" content="HTML, CSS, JavaScript">
6.5 Author
គឺជាកូដសម្រាប់បញ្ជាក់ពីឈ្មោះរបស់អ្នកបង្កើត ឬម្ចាស់កម្មសិទ្ធិនៃទំព័រគេហទំព័រនោះ។ វាជាវិធីសាស្ត្រស្តង់ដារមួយក្នុងការដាក់ «ហត្ថលេខាឌីជីថល» នៅពីក្រោយខ្សែភ្នែករបស់អ្នកទស្សនា ដើម្បីប្រាប់ទៅកាន់កម្មវិធីរុករកបណ្ដាញ (Browser) និងម៉ាស៊ីនស្វែងរក (Search Engines) ឱ្យដឹងថានរណាជាអ្នកសរសេរអត្ថបទ ឬរចនាកូដទំព័រនេះឡើង។
Syntax <meta name="author" content="Your Name">
7 <link>
ប្រើសម្រាប់បង្កើតទំនាក់ទំនង ឬភ្ជាប់ទំព័រ HTML ទៅកាន់ឯកសារខាងក្រៅ។ វាជា Empty Tag (មានតែ tag បើក គ្មាន tag បិទ </link> ទេ) ហើយត្រូវសរសេរនៅក្នុងផ្នែក <head></head> ជានិច្ច។
7.1 External CSS
គឺជាកូដសម្រាប់ភ្ជាប់ឯកសារ CSS ខាងក្រៅ (External CSS) ចូលមកក្នុងទំព័រ HTML។ វាប្រាប់ទៅកាន់កម្មវិធីរុករកបណ្ដាញ (Web Browser) ឱ្យទាញយកស្ទីលម៉ូដ ការដេគ័រពណ៌ រន្ធប្លង់ (Layout) និងពុម្ពអក្សរដែលអ្នកបានរចនានៅក្នុងឯកសារឈ្មោះ style.css មកអនុវត្តលើផ្ទាំងទំព័រ Web ទាំងមូល។
Syntax <link rel="stylesheet" href="style.css">
7.2 Favicon
គឺជាកូដសម្រាប់ដាក់រូបតំណាងគេហទំព័រ (Favicon)។ វាប្រាប់ទៅកាន់កម្មវិធីរុករកបណ្ដាញ (Web Browser) ឱ្យបង្ហាញរូបថត ឡូហ្គោ ឬនិមិត្តសញ្ញាតូចមួយ នៅលើ Tab នៃផ្ទាំង Browser នៅខាងមុខចំណងជើង (Title) នៃគេហទំព័ររបស់អ្នក ក៏ដូចជានៅក្នុងទំព័រ Bookmark ផងដែរ។
Syntax <link rel="icon" href="favicon.ico">
8 <style></style>
ប្រើសម្រាប់សរសេរកូដ CSS នៅផ្ទាល់ក្នុងឯកសារ HTML (ហៅថា Internal CSS) ដើម្បីតុបតែងពណ៌ រូបរាង ទំហំ និងប្លង់ (Layout) នៃធាតុផ្សេងៗលើទំព័រវិប។ វាត្រូវតែសរសេរនៅក្នុងផ្នែក <head></head> ជានិច្ច។
9 <script></script>
ប្រើសម្រាប់បញ្ជ្រាប ឬភ្ជាប់កូដដំណើរការ (Executable Code) ដែលជាទូទៅគឺភាសា JavaScript ទៅក្នុងទំព័រ HTML។ វាមានតួនាទីបង្កើតភាពរស់រវើក និងមុខងារបញ្ជាផ្សេងៗនៅលើគេហទំព័រ (ដូចជា ប៊ូតុងចុចបើកផ្ទាំងដំណឹង ឬការផ្ទៀងផ្ទាត់ទិន្នន័យ)។
Syntax <script>alert("Hello World!");</script>
9.1 link External JavaScrip
គឺជាកូដសម្រាប់ភ្ជាប់ឯកសារ JavaScript ខាងក្រៅ (External JavaScript) ចូលមកក្នុងទំព័រ HTML [script]។ វាប្រាប់ទៅកាន់កម្មវិធីរុករកបណ្ដាញ (Web Browser) ឱ្យទាញយកកូដបញ្ជា កម្មវិធី ឬមុខងារអន្តរកម្ម (Interactions) ដែលអ្នកបានសរសេរនៅក្នុងឯកសារឈ្មោះ script.js មកដំណើរការនៅលើទំព័រ Web របស់អ្នក។
Syntax <script src="script.js"></script>
9.2 Use defer
គឺជាវិធីសាស្ត្រដ៏ល្អបំផុតក្នុងការភ្ជាប់ឯកសារ JavaScript ខាងក្រៅ ដោយបន្ថែមលក្ខណៈ defer ដើម្បីកុំឱ្យទំព័រ Web ដើរយឺត ឬគាំង។
Syntax <script src="script.js" defer></script>
10 <base>
ប្រើសម្រាប់កំណត់អាសយដ្ឋានបណ្ដាញលំនាំដើម (Base URL) និងទិសដៅបើកលីង (Target) សម្រាប់គ្រប់តំណភ្ជាប់ដែលជាប្រភេទ Relative URL (ផ្លូវកូដទម្រង់ខ្លី) ទាំងអស់នៅលើទំព័រវិប។ វាជា Empty Tag (គ្មាន tag បិទទេ) ហើយត្រូវតែមានវត្តមានតែមួយគត់ នៅក្នុងផ្នែក <head></head>។
Syntax <base href="https://example.com/">
10.1 Base URL + Target
គឺជាកូដសម្រាប់កំណត់អាសយដ្ឋានផ្លូវការចម្បង (Base URL) និងទម្រង់នៃការបើក Link សម្រាប់ទំព័រ Web ទាំងមូល។ វាប្រាប់ទៅកាន់កម្មវិធីរុករកបណ្ដាញ (Web Browser) ឱ្យដឹងថា រាល់ Link ភ្ជាប់ទាំងអស់ (តំណភ្ជាប់រូបភាព ឯកសារ ឬទំព័រផ្សេងៗ) ដែលសរសេរជាលក្ខណៈខ្លី (Relative Path) ត្រូវតែយកទៅបូកបន្តពីក្រោយអាសយដ្ឋាន https://example.com/ នេះជានិច្ច។
Syntax <base href="https://example.com/" target="_blank">

.put() គឺជាមុខងាររបស់ Output Stream(ដូចជា cout ឬ ofstream) ដែលប្រើសម្រាប់បង្ហាញតួអក្សរតែមួយ (Single Character) ទៅកាន់អេក្រង់ ឬ File។ វាខុសពី cout << ដែលអាចបង្ហាញទិន្នន័យបានច្រើនប្រភេទព្រោះ .put() ទទួលយកតែតួអក្សរប្រភេទ char មួយប៉ុណ្ណោះ។
Syntax std::cout.put(char ch);
Example
#include <iostream> using namespace std; int main() { char ch = 'Z'; cout.put(ch); cout.put('A'); cout.put('\n'); return 0; }
Output
ZA
2.2 write()
.write() គឺជាមុខងាររបស់ Output Stream(ដូចជា cout ឬ ofstream) ដែលប្រើសម្រាប់សរសេរតួអក្សរជាច្រើនក្នុងពេលតែមួយ។វាខុសពី << ឬ .put() ត្រង់ថា.write() សរសេរទិន្នន័យតាមចំនួនតួអក្សរ(Number of Characters) ដែលយើងកំណត់ជាក់លាក់។
Syntax std::cout.write(pointer_to_char_array, number_of_characters);
Example
#include <iostream> using namespace std; int main() { char text[] = "ABCDE12345"; cout.write(text, 7); return 0; }
Output
ABCDE12
2.3 flush()
.flush() ត្រូវបានប្រើសម្រាប់ បង្ខំឱ្យបញ្ជូនទិន្នន័យពី Buffer ទៅកាន់គោលដៅ (ដូចជា អេក្រង់ ឬ File) ភ្លាមៗ ដោយមិនចាំបាច់រង់ចាំឱ្យ Buffer ពេញនោះទេ។ជាទូទៅ នៅពេលអ្នកប្រើ cout,កុំព្យូទ័រមិនបង្ហាញអក្សរលើអេក្រង់ភ្លាមៗរាល់តួអក្សរនោះទេគឺវាទុកក្នុងMemory បណ្តោះអាសន្ន (Buffer) សិនដើម្បីបង្កើនល្បឿន។ .flush()គឺជាអ្នកបញ្ជាឱ្យ "បោសសម្អាត" និងបញ្ជូនទិន្នន័យទាំងនោះចេញមកក្រៅ។
Syntax std::cout.flush();
Example
#include <iostream> using namespace std; int main() { cout << "Hello "; cout.flush(); cout << "World"; return 0; }
Output
Hello World
3 Input methods
3.1 get()
get() គឺជាមុខងាររបស់ Input Stream (ដូចជា cin ឬ ifstream) ដែលប្រើសម្រាប់ អានតួអក្សរ (Character Input)។ វាមានភាពបត់បែនជាង cin >> ព្រោះវាអាចអានបានទាំង Space (ដកឃ្លា) និង Newline (ការចុះបន្ទាត់)។
Syntax cin.get(name, size);
Example
#include <iostream> using namespace std; int main() { char name[50]; cout << "Enter your name: "; cin.get(name, 50); cout << "Hello " << name; return 0; }
Output
Enter your name: Xiao Yang Hello Xiao Yang
3.2 getline(buf, n)
cin.getline(char* buf, streamsize n) ក្នុងភាសា C++ ត្រូវបានប្រើសម្រាប់ អានអត្ថបទទាំងបន្ទាត់ (រួមទាំងដកឃ្លា)។ វាស្រដៀងទៅនឹង get(buf, n) ដែរ ប៉ុន្តែវាមានភាពងាយស្រួលជាង ត្រង់ថាវា ដកតួអក្សរចុះបន្ទាត់ (\n) ចេញពី Buffer ឱ្យអ្នកតែម្តង។
Syntax cin.getline(buf, n);
Example
#include <iostream> using namespace std; int main() { char name[50]; cout << "Enter your name: "; cin.getline(name, 50); cout << "Hello " << name; return 0; }
Output
Enter your name: Xiao Bao Hello Xiao Bao
3.3 getline(buf, n, delim)
cin.getline(char* buf, streamsize n, char delim) គឺជាទម្រង់ពិសេសនៃ getline() ដែលអនុញ្ញាតឱ្យអ្នក កំណត់តួអក្សរបញ្ចប់ (Delimiter) ដោយខ្លួនឯង ជំនួសឱ្យការប្រើគ្រាប់ចុច Enter (\n) ជាលំនាំដើម។វានឹងអានអត្ថបទរហូតដល់វាជួបតួអក្សរ delim ដែលអ្នកបានកំណត់ ឬរហូតដល់គ្រប់ចំនួន n-1 តួ។
Syntax cin.getline(buffer, size, delimiter);
Example
#include <iostream> using namespace std; int main() { char text[50]; cout << "Enter text: "; cin.getline(text, 50, ' '); cout << "You entered: " << text; return 0; }
Output
Enter text: Xiao Yang You entered: Xiao
3.4 read()
.read() គឺជាមុខងាររបស់ Input Stream (ដូចជា cin ឬ ifstream) ដែលត្រូវបានប្រើសម្រាប់ អានទិន្នន័យជាកញ្ចប់ (Block of characters/Binary data) ពីប្រភពបញ្ចូល។ វាខុសពី >> ឬ getline() ត្រង់ថាវាមិនខ្វល់ពីតួអក្សរពិសេសដូចជាដកឃ្លា ឬការចុះបន្ទាត់ឡើយ។
Syntax stream.read(buffer, number_of_characters);
Example
#include <iostream> using namespace std; int main() { char text[10]; cout << "Enter text: "; cin.read(text, 5); cout << "Data: "; cout.write(text, 5); return 0; }
Output
Enter text: Hello Xiao Yang Data: Hello
3.5 peek()
.peek() ត្រូវបានប្រើសម្រាប់ លួចមើលតួអក្សរបន្ទាប់ នៅក្នុង input stream (ដូចជា cin ឬ ifstream) ដោយ មិនទាញយក តួអក្សរនោះចេញពី stream ឡើយ។មានន័យថា បន្ទាប់ពីអ្នកប្រើ .peek() រួច បើអ្នកប្រើ cin >> ឬ .get() វានឹងនៅតែអានបានតួអក្សរដដែលនោះម្តងទៀត។
Syntax cin.peek();
Example
#include <iostream> using namespace std; int main() { char ch; cout << "Enter character: "; cout << "Peek: " << (char)cin.peek() << endl; cin.get(ch); cout << "Get: " << ch; return 0; }
Output
Enter character: r Peek: r Get: r
3.6 ignore()
.ignore() ត្រូវបានប្រើសម្រាប់ រំលង ឬលុបចោលតួអក្សរ ចេញពី input buffer (សតិបណ្តោះអាសន្ន)។ គេច្រើនប្រើវាបំផុតដើម្បីសម្អាតតួអក្សរ "ចុះបន្ទាត់" (\n) ដែលនៅសេសសល់ក្នុង buffer បន្ទាប់ពីប្រើ cin >> រួច។
Syntax cin.ignore();
Example
#include <iostream> using namespace std; int main() { cin.ignore(50, ','); cout << "Comma skipped"; return 0; }
Output
Xiao Yang Wang Por Wei Mo , Comma skipped
3.7 putback()
.putback() ត្រូវបានប្រើសម្រាប់ ដាក់តួអក្សរមួយត្រឡប់ទៅក្នុង input stream វិញ បន្ទាប់ពីវាត្រូវបានអានដោយមុខងារផ្សេងទៀត (ដូចជា .get())។ តួអក្សរនោះនឹងក្លាយជាតួអក្សរដំបូងគេដែលនឹងត្រូវអាននៅក្នុងប្រតិបត្តិការបន្ទាប់។វាស្រដៀងទៅនឹង .peek() ដែរ ប៉ុន្តែ .peek() គ្រាន់តែលួចមើលដោយមិនទាញចេញពី Buffer ទេ ចំណែក .putback() គឺត្រូវការអាន (ទាញចេញ) សិន ទើបញាត់ចូលទៅវិញតាមក្រោយ។
Syntax cin.putback(character);
Example
#include <iostream> using namespace std; int main() { char ch;cin.get(ch); cout << "Read: " << ch << endl; cin.putback(ch); cin.get(ch); cout << "Again: " << ch; return 0; }
Output
Mo Read: M Again: M
3.8 unget()
.unget() ត្រូវបានប្រើសម្រាប់ រុញតួអក្សរចុងក្រោយគេដែលទើបតែអានរួច ត្រឡប់ទៅក្នុង input stream វិញ។ វាធ្វើឱ្យតួអក្សរនោះ ក្លាយជាតួអក្សរដំបូងគេដែលនឹងត្រូវអានម្តងទៀតនៅក្នុងប្រតិបត្តិការបន្ទាប់។វាដំណើរការស្រដៀងទៅនឹង .putback() ដែរ ប៉ុន្តែវាមានភាពងាយស្រួលជាង ត្រង់ថាអ្នកមិនបាច់បញ្ជូនតួអក្សរ (Argument) ទៅឱ្យវាវិញនោះទេ គឺវាដឹងដោយស្វ័យប្រវត្តិតែម្តង។
Syntax cin.unget();
Example
#include <iostream> using namespace std; int main() { char ch; cin.get(ch); cout << "First read: " << ch << endl; cin.unget(); cin.get(ch); cout << "Second read: " << ch; return 0; }
Output
Por First read: P Second read: P
3.9 gcount()
.gcount() គឺជាមុខងាររបស់ Input Stream (ដូចជា cin ឬ ifstream) ដែលត្រូវបានប្រើសម្រាប់ រាប់ចំនួនតួអក្សរ (Bytes) ដែលអានបានជោគជ័យ ពីប្រតិបត្តិការអានទិន្នន័យចុងក្រោយបង្អស់ដែលមិនកំណត់ទម្រង់ (Unformatted input operation)។ពាក្យ "gcount" មកពីពាក្យថា "Get Count"។
Syntax cin.gcount();
Example
#include <iostream> using namespace std; int main() { char text[20]; cout << "Enter text: "; cin.read(text, 5); cout << "Characters read: " << cin.gcount(); return 0; }
Output
Enter text: Wei Mo Characters read: 5
4 Stream state
4.1 good()
.good() គឺជាមុខងាររបស់ I/O Stream (ដូចជា cin, cout, ifstream, ofstream) ដែលត្រូវបានប្រើសម្រាប់ ពិនិត្យស្ថានភាពរបស់ Stream ថា តើវាស្ថិតក្នុងស្ថានភាពធម្មតា និងអាចដំណើរការបន្តទៀតបានដែរឬទេ។វានឹងបញ្ជូនតម្លៃមកវិញជាប្រភេទ Boolean (true ឬ false)។
Syntax stream.good()
Example
#include <iostream> using namespace std; int main() { int x; cin >> x; if(cin.good()) {cout << "Input is valid"; } else {cout << "Input error";} cout << "\ncin.good() is " << cin.good(); return 0; }

4.2 fail()
.fail() គឺជាមុខងាររបស់ I/O Stream (ដូចជា cin, cout, ifstream) ដែលត្រូវបានប្រើសម្រាប់ ពិនិត្យមើលថាតើមានកំហុសកើតឡើងដែរឬទេ ក្នុងប្រតិបត្តិការអាន ឬសរសេរទិន្នន័យចុងក្រោយ។វាជាមុខងារផ្ទុយពី .good() ហើយវានឹងបញ្ជូនតម្លៃមកវិញជាប្រភេទ Boolean (true ឬ false)។
Syntax cin.fail();
Example
#include <iostream> using namespace std; int main() { int x; cout << "Enter a number: ";cin >> x; if(cin.fail()) {cout << "Input failed! Not a number."; } else {cout << "You entered: " << x;} cout << "\ncin.fail() is " << cin.fail(); return 0; }
Output
Enter a number: a65 Input failed! Not a number. cin.fail() is 1
5 Format flag methods
5.1 flags(f)
.flags(f) គឺជាមុខងាររបស់ I/O Stream (ដូចជា cout, cin, ifstream) ដែលត្រូវបានប្រើសម្រាប់ កំណត់ទង់ជាតិទម្រង់ (Format Flags) ទាំងអស់ក្នុងពេលតែមួយ [cppreference.com]។វាខុសពីម៉ានីពូឡាទ័រ (Manipulators) ដូចជា hex ឬ scientific ដែលកែប្រែទម្រង់ម្តងមួយៗ មុខងារ .flags(f) នឹងលុបចោលរាល់ទម្រង់ចាស់ៗទាំងអស់ ហើយជំនួសមកវិញនូវសំណុំទម្រង់ថ្មីដែលអ្នកបានបញ្ជូនទៅ ។
Syntax stream.flags(f);
Example
#include <iostream> using namespace std; int main() { int num = 797; // Save original flags ios::fmtflags f = cout.flags(); // 1. showbase============================== cout.flags(ios::showbase); cout << "showbase: " << hex << num << endl; // 2. uppercase============================= cout.flags(ios::showbase | ios::uppercase); cout << "uppercase: " << hex << num << endl; // 3. dec=================================== cout.flags(ios::dec); cout << "decimal: " << num << endl; // 4. oct=================================== cout.flags(ios::oct); cout << "octal: " << num << endl; // 5. hex=================================== cout.flags(ios::hex); cout << "hexadecimal: " << num << endl; // 6. showpos=============================== cout.flags(ios::showpos); cout << "showpos: " << 100 << endl; // Restore original flags=================== cout.flags(f); return 0; }
Output
showbase: 0x31d uppercase: 0X31D decimal: 797 octal: 1435 hexadecimal: 31d showpos: +100
5.2 setf(flag)
.setf() (មកពីពាក្យថា Set Flags) គឺជាមុខងាររបស់ I/O Stream (ដូចជា cout) ដែលត្រូវបានប្រើសម្រាប់ បើក ឬកំណត់ទង់ជាតិទម្រង់ (Format Flags) ជាក់លាក់ណាមួយ ដើម្បីគ្រប់គ្រងរបៀបបង្ហាញទិន្នន័យលើអេក្រង់។ វាខុសពី .flags(f) ត្រង់ថា .setf() គ្រាន់តែកែប្រែ ឬបន្ថែមទម្រង់ដែលអ្នកចង់បាន ដោយមិនលុបចោលរាល់ទម្រង់ផ្សេងទៀតដែលមិនទាក់ទងនោះឡើយ។
Syntax cout.setf(ios::hex, ios::basefield);
Example
#include <iostream> using namespace std; int main() { cout.setf(ios::hex, ios::basefield); cout.setf(ios::scientific, ios::floatfield); cout << 255 << endl;cout << 10.0 << endl; return 0; }
Output
